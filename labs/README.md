# Application of BIM using Revit — Hands-On Labs

Ten hands-on Autodesk Revit labs for the WSQ course **Application of BIM using Revit** (TGS-2022015370), aligned to the Skills Framework TSC Building Information Modelling Application (BEV-TEM-3027-1.1-1). Each lab has its own folder with a README and the Revit dataset files it uses (also downloadable from the LMS at https://lms-tms.tertiaryinfotech.com).

| Lab | Title | Topic | Datasets |
|---|---|---|---|
| 01 | [Get Started with Revit](lab-01-get-started-with-revit/) | Topic 01: Introduction to BIM and Revit | — |
| 02 | [Convert 2D Information into a 3D Model](lab-02-convert-2d-information-into-a-3d-model/) | Topic 01: Introduction to BIM and Revit | Planning Site.pdf, Site Image.png, Planning Site solution.rvt |
| 03 | [Modeling Walls — Reveals, Embedded and Curtain Walls](lab-03-modeling-walls-reveals-embedded-and-curtain-walls/) | Topic 02: BIM Modeling | Embed Walls.rvt, Embed Walls solution.rvt |
| 04 | [Floors, Ceilings, Roofs and Openings](lab-04-floors-ceilings-roofs-and-openings/) | Topic 02: BIM Modeling | Create Ceilings.rvt, Create Ceilings Solution.rvt |
| 05 | [Stairs, Railings and Structural Elements](lab-05-stairs-railings-and-structural-elements/) | Topic 02: BIM Modeling | Studio Block.rvt, Studio Block Structure.rvt, Studio Block Finished.rvt |
| 06 | [Terrain, Building Pad and Conceptual Mass](lab-06-terrain-building-pad-and-conceptual-mass/) | Topic 02: BIM Modeling | — |
| 07 | [View Templates, Schedules and Quantity Takeoffs](lab-07-view-templates-schedules-and-quantity-takeoffs/) | Topic 03: BIM Application | Create View Template.rvt, Create View Template solution.rvt |
| 08 | [Energy Analysis and Design Compliance Checks](lab-08-energy-analysis-and-design-compliance-checks/) | Topic 03: BIM Application | — |
| 09 | [Sheets, Worksharing and Linked Models](lab-09-sheets-worksharing-and-linked-models/) | Topic 04: BIM Documentation | CA-L15-01-Use PDF and Images.rvt |
| 10 | [BIM e-Submission Standards Check](lab-10-bim-e-submission-standards-check/) | Topic 04: BIM Documentation | — |

Lab 1 uses the Autodesk sample project installed with Revit (`rac_basic_sample_project.rvt`); Lab 6 uses `GSG_03_Terrain_Pad.rvt` from the Revit Getting Started files (or any small project model); Labs 8 and 10 continue on your own course model.
